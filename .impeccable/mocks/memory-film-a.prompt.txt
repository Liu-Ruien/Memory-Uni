Use case: ui-mockup
Asset type: high-fidelity north-star comp for a desktop web experience, 16:9 viewport, Memory-Uni Memory Film entry screen
Primary request: Design a complete full-screen interactive UI for “沉浸式回忆”, not a poster. The core concept is “a graduation film reel that binds itself”: the same real university photos will later morph through seven spatial formations.
Input images: Image 1 is the existing Memory-Uni visual identity reference; carry over its deep teal film chapter, warm-white type, subtle youthful coral accent, restrained iOS-like glass controls and rounded language, but do not copy its exact section layout or red annotations. Image 2 is real product content; preserve it as a recognizable featured group photo within the UI, do not alter faces.
Structure: no conventional header. A small glass back control at top left. A quiet period/timecode capsule centered at top. The central 58% of the viewport is a sculptural 3D photo-gate: the real group photo leads, with five partially visible photo sheets curving behind it into a loose film aperture, clearly an interface preparing to move. Left-lower quadrant contains the large Chinese title “把四年，重新放映一次。” and one short line “同一批照片，将重新组成七段共同回忆。” Bottom right owns the primary liquid-glass coral control “开始放映” with a play symbol; beside it state “61 张照片 · 约 01:09”. Along the bottom is a fine seven-chapter timeline/waveform that proves this is a playable film interface.
Visual world: deep teal-black photographic emulsion, not purple. Paper-white photo edges, mint reflections, coral-red locator/play accent. Sparse illuminated dust. Curved continuous iOS radii, physical glass only for functional controls, no decorative glass card grid.
Typography: distinctive condensed display sans for Chinese title, clear humanist sans for UI, strong hierarchy, no generic futuristic mono costume.
Interaction cues: start button looks always active and tactile; visible keyboard focus language; progress and chapter labels are legible.
Constraints: real photos are the subject, not abstract art. No social-media chrome, no hearts, no neon purple-blue gradient, no bento dashboard, no fake testimonials, no phone mockup, no watermark. Avoid tiny unreadable text. The result must unmistakably read as a desktop web interface the visitor can operate.
